﻿# GLAUCOMA-ED2

Projeto desenvolvido para a disciplina de Estrutura de Dados II.

## Descrição

Sistema de triagem de glaucoma utilizando estruturas de dados (ABB, AVL e Heap Máxima) e um modelo de Inteligência Artificial para classificação de imagens.

## Como executar

```bash
git clone https://github.com/PerlaBezerra/GLAUCOMA-ED2.git
cd GLAUCOMA-ED2
git lfs pull
python main.py
```
